⟦How to join‖Cara ikut⟧ __LB_TITLE__

⟦Ask the admin for your install command. It contains your personal token, so do not share it with anyone. One token per person; if you install it on several laptops, they all count toward the same name.‖Minta perintah install ke admin. Isinya token pribadi kamu, jadi jangan dibagikan ke orang lain. Satu token untuk satu orang; kalau dipasang di beberapa laptop, semuanya dihitung ke nama yang sama.⟧

⟦Install‖Pasang⟧

  1. ⟦Run the command from the admin in Terminal (macOS / Linux) or PowerShell (Windows).‖Jalankan perintah dari admin di Terminal (macOS / Linux) atau PowerShell (Windows).⟧
  2. ⟦Close and reopen Claude Code.‖Tutup lalu buka lagi Claude Code.⟧
  3. ⟦Use Claude Code as usual. Your numbers show up on the leaderboard a few seconds later.‖Pakai Claude Code seperti biasa. Angka muncul di leaderboard beberapa detik kemudian.⟧

⟦What gets sent‖Apa yang dikirim⟧

  1. ⟦Token counts per type (input, output, cache) and model.‖Jumlah token per tipe (input, output, cache) dan model.⟧
  2. ⟦The cost estimate calculated by Claude Code, session count, and active time.‖Estimasi biaya yang dihitung Claude Code, jumlah sesi, dan waktu aktif.⟧

⟦Prompt contents, responses, code, and file names are not sent. The installer only adds a few‖Isi prompt, jawaban, kode, dan nama file tidak dikirim. Installer hanya menambah beberapa variabel⟧ OTEL_* ⟦variables to the‖ke blok⟧ env ⟦block in‖di⟧ ~/.claude/settings.json⟦, after first making a backup of that file.‖, dan membuat backup file itu dulu.⟧
